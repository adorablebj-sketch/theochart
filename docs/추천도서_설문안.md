# 신학 필독서 추천 설문 (교수·목회자용)

> 구글폼이나 카카오톡 메시지로 그대로 보내도 되는 문안입니다. 5분 안에 끝나게 짧게 유지하세요.

## 보내는 글 (예시)

교수님, 황병준 목사입니다. 복음주의·개혁주의 관점에서 기독교 서적을 안내하는 사이트를 만들고 있습니다. 서점 판매 순위만으로는 신학의 기본서·교과서가 드러나지 않아서, 각 분야 선생님들께 "꼭 읽어야 할 책"을 여쭙고 그 추천을 모아 공개하려고 합니다. 10권만, 5분이면 됩니다. 추천자 성함과 소속은 동의하신 경우에만 표기합니다.

## 문항

1. 성함 / 소속(학교·교회) / 전공 분과 (조직신학·성경신학·구약·신약·교회사·실천신학·선교·기독교교육 등)
2. 현재 상태: 현직 / 은퇴 / 기타
3. **이 분야 필독서 10권** — 각 권마다 *제목 · 저자 · 한 줄 이유*
   (입문자용과 신학생용을 구분해 주시면 더 좋습니다)
4. 그중 **딱 한 권만 고른다면**?
5. 이 분야에서 **꼭 여쭤봐야 할 분 2~3명** (성함·소속)
6. 공개 동의: 실명·소속 표기 동의 / 익명("조직신학 교수 A")으로 표기 / 집계에만 사용
7. (선택) 본인 저서 중 입문자에게 권하고 싶은 책

## 작고한 학자의 추천 (문헌 추천)

직접 여쭐 수 없는 분들은 남기신 기록으로 넣습니다 — 강의안, 책 속 "더 읽을 책", 서평, 필독서 목록.
반드시 출처(책 제목·연도·쪽)를 함께 기록하고, 사이트에는 "문헌 추천"으로 구분 표기합니다.

## 집계 원칙 (사이트 방법론에 공개)

- 한 책의 추천 수 = 추천한 사람 수 (한 사람이 여러 번 추천해도 1)
- "딱 한 권"은 가중치 2
- 추천자는 학교·분과·상태(현직/은퇴/문헌)를 함께 표시해 균형이 보이게
- 연 1회 갱신, 연말 "올해의 신학 필독서 100선" 발표
